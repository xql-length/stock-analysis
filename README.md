## 📌 简介

这是一个可复用的 AI Skill 文档，用于分析同一家公司在 A 股与 H 股的价差。框架经过华虹宏力（688347.SH / 1347.HK）完整实战校验，覆盖从数据采集到交易时机的全链路。

**核心产出**：轨迹 → 成因 → 合理区间 → 收敛可能性 → 资金信号 → 时机结论

## 🏗 框架架构

```
Step 0 标的确认 → Step 1 数据获取 → Step 2 溢价轨迹还原 → Step 3 成因四层诊断
→ Step 4 合理区间判定 → Step 5 催化剂概率评估 → Step 6 南向信号定位 → Step 7 情景矩阵与时机
```

### 设计亮点

- **数据驱动优先**："先取数后下结论"，每个数字标注来源与日期
- **动态而非静态**：连续性 > 单日数据，追踪趋势而非快照
- **主动纠偏**：预设"常见误区"，防止陷入价值陷阱
- **可量化的行动**：目标价矩阵、情景概率、三级资金信号

### 底层逻辑（三套并行系统）

| 系统 | 核心规则 |
|---|---|
| 估值线 | 基本面两端共享，但定价叙事不同；通过 PE 和备考 EPS 剥离情绪溢价 |
| 资金线 | 四级信号刻度尺（弱/中/强/证伪），铁律："连续性 > 单日金额" |
| 路径线 | 收敛以"A 回落为主"为底层概率假设，指导情景矩阵权重分配 |

## 📊 框架核心模块

| 模块 | 步骤 | 关键产出 |
|---|---|---|
| 标的确认 | Step 0 | 消除歧义，固定代码 |
| 数据获取 | Step 1 | iFinD 行情 + 基本面 + 南向资金 + 汇率 |
| 轨迹还原 | Step 2 | 溢价率时间序列 + 形态判断 |
| 成因诊断 | Step 3 | 制度/筹码/基本面/汇率四层归因 |
| 合理区间 | Step 4 | 三参照系交集 → 中枢 ± 波动带 |
| 催化剂评估 | Step 5 | 逐项概率 × 空间 × 证伪条件 |
| 资金信号 | Step 6 | 三级信号判定南向阶段 |
| 时机矩阵 | Step 7 | 四象限目标价 + 时机三件套 |

## ⚠️ 常见误区（框架主动纠正）

1. **价差大 ≠ 套利空间** — A/H 不可互换交割，无风险套利不存在
2. **收敛不靠 H 涨** — 历史路径以 A 回落为主
3. **"A 高位低波动"是强假设** — 高 PE + 高融资盘常态是双向剧震
4. **单日南向数据不下结论** — 看连续性与周度累计
5. **汇率被动放大价差** — 比较时统一折 RMB
